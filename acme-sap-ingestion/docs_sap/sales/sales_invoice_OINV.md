# OINV — Sales Invoice (header)

**SAP table:** OINV  
**Bronze name:** sales_invoice_oinv  
**Total columns in raw:** 41

## Description

Stores the headers of sales invoices issued to customers (A/R Invoice in SAP B1). Each row represents a fiscal document. Because it is `incremental_upsert`, the raw layer always keeps the most recent state of each document — updates (including cancellations) overwrite the existing record via MERGE on the `DocEntry` key.

## Relationships

OINV is the final fiscal document of the sales cycle. Each invoice may have originated from a sales order (ORDR) or a quote (OQUT), or have been issued directly with no base document. Every issued invoice automatically generates an accounting entry in OJDT.

**Child tables — join on `DocEntry`:**
- INV1 (`sales_invoice_lines_inv1`) — invoice line items
- INV3 (`sales_invoice_expenses_inv3`) — additional charges (freight, insurance, etc.)
- INV6 (`sales_invoice_installments_inv6`) — payment installments
- INV12 (`sales_invoice_usage_inv12`) — fiscal usage/destination extension

**Parent tables — OINV references:**
- OJDT via `TransId` — accounting entry generated by the issuance
- OSLP via `SlpCode` — responsible sales employee
- OBPL via `BPLId` — issuing branch
- NFN1 via `SeqCode` — invoice series

**Source traceability** (via INV1, not directly on OINV):
- ORDR via `INV1.BaseEntry` where `INV1.BaseType = 17` — sales order that originated the invoice (confirmed in the database)
- OQUT via `INV1.BaseEntry` where `INV1.BaseType = 23` — quote that originated the invoice (confirmed in the database)
- ORIN via `INV1.BaseEntry` where `INV1.BaseType = 13` — return that generated a credit invoice (confirmed in the database)
